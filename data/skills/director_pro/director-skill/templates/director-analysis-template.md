# 导演分析产出模板

导演讲戏本部分使用纯文本格式，人物/场景清单使用 XML 格式。不再输出 Markdown 表格。

---

## 导演讲戏本

每个剧情点 = 一段完整叙事 = 一次 Seedance 2.0 生成任务。
段落内可包含多组镜头（如蒙太奇、快速闪回），但叙事上必须是一个完整段落。

```markdown
## P01 [剧情标题]

- 人物：[出场人物]
- 场景：[场景名（多场景段落用顿号分隔）]
- 镜头组：[单镜头 / 多镜头（X 组）]
- 时长建议：[5s/8s/10s/15s]

**导演阐述**：
[完整的画面描述，包含走位、动作、台词、镜头感觉、光影氛围。
用自然流畅的叙述融合所有维度，不要分条列举。
像给演员讲戏一样，把脑海中的影像说出来。
多镜头段落还需描述镜头切换方式、子画面节奏、整段叙事弧线。]

---

## P02 [剧情标题]
...
```

## 人物清单（仅 XML）

```xml
<characters>
<item name="林薇" type="新增" description="干练短发、鹅蛋脸、职业西装" />
<item name="母亲" type="新增" description="花白短发、圆润脸型、朴素棉衣" />
<item name="夜（黑豹）" type="变体" description="雄壮黑豹、琥珀色眼睛" />
</characters>
```

素材状态取值：新增/复用/变体。群演和一次性配角不列入清单。

---

## 场景清单（仅 XML）

```xml
<scenes>
<item name="办公室" time="深夜" lighting="冷白荧光灯、暗蓝" atmosphere="冷清、压抑" type="新增" />
<item name="火车站" time="傍晚" lighting="暖黄夕阳" atmosphere="喧闹、过渡" type="新增" />
</scenes>
```

---

## 输出规范

- 使用与剧本原文相同的语言，勿擅自翻译
- 导演讲戏本采用叙事描述式，不要分条列举
- 人物清单和场景清单只输出 XML，不输出 Markdown 表格
