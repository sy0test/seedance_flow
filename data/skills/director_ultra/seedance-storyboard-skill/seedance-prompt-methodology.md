# Seedance 2.0 提示词方法论

[第一性原则]

    导演意图优先
        - 导演讲戏本是创意源头，提示词是技术翻译
        - 不要偏离导演的画面意图，不要自行添加导演未描述的内容
        - 如果导演阐述中缺少某些技术细节（如具体运镜），分镜师可以补充，但必须服务于导演的叙事意图

    叙事描述式
        - Seedance 2.0 擅长理解长段叙事性描述
        - 用完整的段落描述，像写电影脚本一样
        - 不要用关键词堆叠，不要用标签式描述

    参考图已见原则
        - Seedance 2.0 能"看到"通过 @引用 传入的参考图
        - 不需要重复描述参考图中已有的静态内容（如人物长相、场景布局）
        - 重点描述"变化"：动作、运动、情绪转变、镜头运动

    一条提示词一段叙事
        - 每条提示词对应一次生成任务，产出一条视频
        - 一条提示词内可包含多组镜头（如蒙太奇、连续切换），但叙事上必须连续
        - 不要在一条提示词中塞入叙事上不相关的场景

    节拍密度约束
        作用于每个连续镜头内，非整段：
        - 底层规律：1 拍 ≈ 2.5 秒屏幕时间。节拍太密，AI 生成的动作会糊、跳、不自然。
        - 多镜头段落的节拍分布在各镜头切换中，每个镜头各自遵守密度约束，总节拍可超单镜头上限。

    头尾安全区
        每次 Seedance 生成的前 0.5s 和后 0.5s 为安全区，不放关键内容：
        - 开头：先给环境或主体一个静态建立
        - 结尾：让动作自然收住或保持可衔接的姿态

[平台约束]

    输入限制（单条提示词 / 单次生成任务维度）
        | 输入类型 | 数量上限 | 支持格式 | 大小限制 |
        |---------|---------|---------|---------|
        | 图片    | ≤ 9 张  | jpeg、png、webp、bmp、tiff、gif | 每张 < 30 MB |
        | 视频    | ≤ 3 个  | mp4、mov | 每个 < 50 MB，总时长 2-15s |
        | 音频    | ≤ 3 个  | mp3、wav | 每个 < 15 MB，总时长 ≤ 15s |
        | 文本    | 自然语言提示词 | — | — |
        | **总文件数** | **≤ 12 个** | — | — |

        注意：以上限制是每条提示词（每次 Seedance 生成）的限制，不是全文档限制。
        素材对应表是全文档的总映射表，@图片 总数可以超过 9 张。

    输出参数
        - 生成时长：4-15 秒（可自由选择）
        - 自带音效/配乐
        - 视频总像素数范围：480p（640×640）至 720p（834×1112）

    内容限制
        - 不支持写实真人脸部素材（图片和视频均不可），系统会自动拦截
        - 优先上传对画面或节奏影响最大的素材，合理分配文件数量


[提示词结构]

    基本结构
        1. 素材引用声明（开头）
        2. 场景/环境描述
        3. 主体动作与运镜
        4. 光影/氛围/声音
        5. 风格/技术参数（可选）

    分时段描述（10秒以上推荐使用）
        当生成时长 ≥ 10 秒时，推荐按时间段精确控制画面内容：

        0-3秒：[开场画面描述、运镜、动作]
        3-6秒：[中段发展]
        6-10秒：[高潮或关键动作]
        10-15秒：[收尾、定格画面]

        分时段描述与节拍密度约束配合使用：
        - 每个时间段内的动作密度不要超载
        - 时间段之间的衔接要自然
        - 多镜头段落中，每个时间段可对应不同的子场景/镜头
        - 头尾安全区规则仍然适用（首段开头0.5s、末段结尾0.5s）

    完整示例
        以@图片1中的林薇为主角，场景参考@图片3的深夜办公室。
        中景，林薇独自坐在工位前，冷白荧光灯照亮她疲惫的面容。
        她揉了揉太阳穴，目光从电脑屏幕缓缓移开，身体靠向椅背。
        视线转向窗外，城市灯火稀落。她轻轻叹了口气，低声自语："又是一个人。"
        镜头从她的侧脸慢慢推向窗外的夜色，整体氛围冷寂孤独，电影感。

    分时段示例（15秒）
        以@图片1中的林薇为主角，场景参考@图片3的深夜办公室。
        0-3秒：远景建立，空旷的办公区只有角落一盏台灯亮着，林薇的剪影映在落地窗上。
        4-8秒：中景推近，林薇揉太阳穴，目光从屏幕移开，身体缓缓靠向椅背，表情从专注转为疲惫。
        9-12秒：特写她的侧脸，视线转向窗外，城市灯火稀落，轻声自语："又是一个人。"
        13-15秒：镜头缓慢拉远，林薇的身影在空旷办公区中越来越小，画面定格。
        音效：键盘声渐弱、空调低鸣、窗外远处的车流声。电影感，冷寂孤独。

[多段镜头结构框架（Timed Segment Architecture）]

    当单条提示词时长 ≥ 8 秒时，将一个场景（P）拆分为多个 timed segment（子镜头），每个 3-5 秒。每个 segment 有独立的时间码、镜头类型、光影设计和声音设计。

    段的基本结构（4 必选 + N 可选）：
    - 【镜头类型 / English Shot Type】— 景别+运镜的主体描述
    - 光影设计：— 光源方向、色温、明暗对比
    - 动作与情绪：— 角色面部细节、肢体语言、心理状态
    - 声音设计：— 环境音/动作音效/配乐/台词渲染
    - 【情绪空镜 / Cutaway】— 0.5 秒极速闪切（N 可选）
    - 听觉突变：— 音效骤变/真空抽离（N 可选）

    段间连接方式：
    - 硬切（Hard Cut）：节奏转换点，最常用
    - 闪切（Cutaway / Subliminal Cut）：0.5 秒极速插入空镜，强化情绪
    - 音画错位（L-Cut / J-Cut）：下一段的音频提前在前一段尾声中入场

    段落跨度不宜超过 5 秒。推荐将时长拆分为 2-4 个 3-5 秒的子段落，每个承担一个核心叙事职能（情绪转折、动作高光、环境揭示等）。

[竖屏视听语言体系（Vertical Screen Cinematography）]

    9:16 竖屏的构图逻辑与横屏完全不同。竖屏不是"横屏裁切"，而是一种独立的视觉语言。

    Z 轴纵深构图（Z-Axis Depth）
        利用前景、主体、背景三层制造空间纵深感。前景物体放大置于画面底部，与后景形成强烈远近对比。

    前景遮挡转场
        用巨大、模糊的前景物体划过或砸入画面，实现场景切换。参考：利爪撕破前景、摩托车轮砸入画面下方 60%。

    垂直三段式构图
        上部（40%）：天空、远景、压迫性存在
        中部（35%）：主体角色、核心动作
        下部（25%）：地面、前景道具、动态引导

    底光与顶光的情绪符号化
        - 顶光：来自画面上方的锐利光柱，制造神圣感或暴露感
        - 底光：来自画面下方的惨白反射光，制造阴森、怪物感

    阴影吞噬（Shadow Encroachment）
        利用竖屏的垂直空间表现黑暗从上方侵蚀或阴影从底部向上蔓延。

[主观化声音设计体系（Subjective Soundscape）]

    声音设计应遵循"角色心理状态驱动"原则，而非客观还原环境音。

    听觉状态四象限：
    - 微观态：极度放大人体内部声（呼吸、心跳、骨骼），切断环境音。适用于濒死苏醒、惊恐凝视
    - 真空态：所有声音瞬间抽离，1-2秒绝对死寂。适用于突变前、重大揭示前
    - 爆发态：音量骤增，低频轰鸣或高频尖啸。适用于动作高潮、撞击
    - 沉浸态：混响+空间感恢复，环境音铺开。适用于场景建立、氛围延续

    音效分层模板：
    - 底层（Drone）：持续低频嗡鸣或环境底噪，维持空间感
    - 中层（Foley）：动作音效、衣物摩擦、脚步声——ASMR 级精度放大
    - 顶层（Impact）：枪声、撞击、尖叫——音画同步点，做低频强化

    特殊技巧：
    - 主观听觉切断：角色处于极度恐惧/濒死时，切断所有环境音，只保留生理声
    - 3D 环绕处理：关键音效（嘶吼、低语）做声像定位增强沉浸

[运镜词汇]

    景别
        - 极致特写：仅拍摄眼睛、嘴巴等细节
        - 面部特写：人脸充满画面
        - 中近景：头部和肩部
        - 中景：腰部以上
        - 全景：展示完整人物
        - 远景 / 建立镜头：展示完整环境

    推拉类
        - 推镜头 / 缓慢推近：聚焦、紧张、亲密
        - 拉镜头 / 缓慢拉远：揭示、疏离、结束感
        - 滑动变焦 / 眩晕效果：心理冲击

    横纵摇类
        - 左摇 / 右摇：环顾、跟随水平运动
        - 上摇 / 下摇：强调高度、规模
        - 快速横摇：转场、惊讶

    环绕类
        - 环绕主体：立体感、动感
        - 弧形运动：戏剧性、强调
        - 半环绕（180度）：对话、对峙

    跟拍类
        - 跟拍镜头：跟随主体移动
        - 背后跟拍：跟随主体背影
        - 侧面跟拍：平行跟随
        - 一镜到底：全程无剪辑的连续镜头

    升降类
        - 上升镜头：史诗感、希望
        - 下降镜头：压迫、沉重
        - 航拍镜头：规模、全景

    高级运镜
        - 希区柯克变焦：推拉+变焦的眩晕效果，表现心理冲击
        - 鱼眼镜头：超广角畸变，营造扭曲不安感
        - 低角度仰拍：低机位向上拍摄，增加英雄感/压迫感
        - 俯拍 / 鸟瞰：从高处向下拍摄，全局感
        - 第一人称主观视角：从角色视角出发，沉浸感
        - 快速摇镜：极速水平旋转产生运动模糊
        - 机械臂跟随：多角度灵活跟随人物视线

    手持与固定
        - 手持镜头：真实感、紧张
        - 固定机位：稳定、庄重

[动作词汇]

    面部
        - 缓慢睁眼、微笑浮现、目光转移、眉毛上扬
        - 表情从X转为Y、咬嘴唇、眼眶泛红

    头部
        - 转头、微微歪头、缓慢点头、抬头、低头

    身体
        - 呼吸起伏、前倾、后仰、站起、坐下
        - 向前走、伸出手、拥抱

    手部
        - 举手、握紧、手指动作、比划

    环境互动
        - 头发随风飘动、衣服飘动、水花飞溅
        - 落叶飘落、烟雾升起、尘埃飘浮

[速度修饰词]

    缓慢/轻柔：缓慢、轻柔、渐渐、微妙、细腻
    中等/自然：平稳、稳定、自然、流畅
    快速/强烈：快速、迅速、突然、戏剧性、爆发

[氛围与风格词汇]

    画面风格
        - 电影感、影片质感、大片风格、纪录片风格
        - 电影级质感，胶片颗粒，浅景深
        - 2.35:1宽银幕，24fps
        - 黑白水墨风格 / 动漫风格 / 超写实
        - 高饱和霓虹色调，冷暖对比

    情绪氛围
        - 戏剧性、紧张、悬疑、浪漫、梦幻、怀旧
        - 神秘、欢快、忧郁、暗黑奇幻、仙侠高燃
        - 喜剧风格，表情夸张
        - 温暖治愈、史诗恢宏

[音频设计]

    音频是 Seedance 2.0 的重要能力，提示词中应包含音频指导：

    背景音乐
        - 直接描述风格：背景音乐：恢宏大气 / 紧张悬疑 / 温暖治愈
        - 引用参考：背景BGM参考 @音频1
        - 引用视频中的音乐：音乐风格参考 @视频1

    音效设计
        - 环境音效：走路声、人群声、汽车声、雨声、风声
        - 动作音效：脚步声、呼吸声、衣料摩擦声
        - 情绪音效：心跳声、钟表声、回声

    音画同步
        - 转场画面与音乐节奏卡点
        - 脚步声、呼吸声必须与画面动作贴合
        - 音乐高潮与画面高潮同步

    旁白/对话
        - 角色对白直接写入提示词，用引号标注
        - 可指定音色参考：旁白音色参考 @视频1
        - 可指定语气：哽咽、怒吼、低语、坚定

[视频操作模式]

    除了标准的"从零生成"，Seedance 2.0 还支持以下操作模式，分镜师在需要时可以使用：

    视频延长（向后）
        将 @视频1 延长[时长]。
        [描述延长部分的画面内容]
        注意：生成时长应选择"新增部分"的时长（如延长5秒，生成长度也选5秒）

    视频延长（向前）
        向前延长[时长]，[描述前置画面内容]

    视频编辑
        保留原视频大部分内容，定向修改特定元素：
        - 角色替换：将 @视频1 中的角色换成 @图片1 的角色
        - 元素添加：在 @视频1 的基础上添加 [新元素]
        - 剧情修改：在 @视频1 的基础上改变 [具体情节]

    视频融合
        将多个视频片段衔接融合：
        @视频1 的画面逐渐过渡到 @视频2，[描述过渡方式]

[从导演讲戏到提示词的转化步骤]

    1. 提取素材引用
        - 从导演阐述的人物和场景字段，对应 character-prompts.md 和 scene-prompts.md 中的素材
        - 在提示词开头声明引用，明确每个引用的用途

    2. 提取核心动作
        - 从导演阐述中识别主要动作链
        - 保留具体物理动作，删除抽象描述

    3. 提取运镜意图
        - 从导演阐述中识别镜头运动描述
        - 转化为规范的运镜语言
        - 如果导演未明确指定运镜，根据情绪和叙事目的补充

    4. 提取声音/台词
        - 从导演阐述中提取对白、自语、环境音
        - 保持原文台词不变
        - 补充音效设计和背景音乐指导

    5. 判断是否使用分时段描述
        - 时长 ≥ 10 秒：推荐使用分时段描述
        - 时长 < 10 秒：使用连续段落描述即可

    6. 整合为完整提示词
        - 按照提示词结构组织
        - 确保叙述流畅、连贯
        - 控制在合理长度（与时长匹配）
        - 检查每个 @引用 都有明确的用途说明

[禁忌规则]

    绝对禁忌
        - 否定句（"不要移动" → "保持静止"）
        - 重复参考图中已有的静态内容
        - 抽象概念（"体现自由" → 用具体动作表达）
        - 一条提示词中包含叙事上不相关的场景
        - @引用不指定用途（"参考@视频1" → "参考@视频1的运镜效果"）
        - 上传写实真人脸部素材

    避免事项
        - 过长提示词（控制信息密度与时长匹配）
        - 违反物理规律的动作
        - 与参考图内容矛盾的描述
        - 指令冲突（同时要求"固定镜头"和"环绕镜头"）
        - 单个连续镜头内节拍过密
        - 素材上传了但提示词中未用 @ 标注用途
        - 时长与内容密度不匹配
