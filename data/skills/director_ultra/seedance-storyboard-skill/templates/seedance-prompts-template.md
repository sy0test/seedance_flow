# ULTRA 版 Seedance 2.0 提示词产出模板

所有剧情点输出完毕后，**统一使用 XML 容器标签包裹所有条目**。不再输出 Markdown 格式。

---

## @引用语法

使用 Seedance 2.0 原生 @引用语法：
- @图片1、@图片2... → 参考图片（人物/场景参考）
- @视频1、@视频2... → 参考视频
- @音频1、@音频2... → 参考音频
- 编号与文档头部素材对应表一一对应

---

## 输出格式（唯一格式）

```xml
<references>
<reference ref="@图1" name="林薇" type="人物参考" />
<reference ref="@图2" name="办公室" type="场景参考" />
</references>

<shots>
<shot id="P01" duration="10" characters="林薇@图1,夜（黑豹）" scenes="王国大厅@图3">【导演视觉与听觉宣言 / Director's Vision】真人写实奇幻短剧质感，16:9 宽银幕构图，以宏伟圆形议事大厅为视觉基底，冷蓝高窗光与桌面烛火形成冷暖分裂，制造"哀悼被权力亵渎"的压迫氛围。
*00:00 - 00:03 | 穹顶压下 / Descending Establishing Shot*
【下降建立镜头 / Descending Establishing Shot】镜头从高耸穹顶缓慢俯冲，古老魔法图腾和王室纹样掠过画面，最终压到中央圆桌。
光影设计：灰蓝冷光从左上方高窗斜落，与桌面烛火的暖黄形成强烈冷暖分裂，制造审判席般的压迫感。
动作与情绪：圆桌旁的身影在宏大空间中被压缩成渺小剪影，暗示权力结构中的无力感。
声音设计：环境音是大厅空旷回声、远处烛火轻响和低沉男声私语，混响极重，犹如从深渊底部传来。
*00:03 - 00:06 | 银杯与轻蔑 / Insert Close-up*
【插入特写 / Insert Close-up】硬切到手部特写，他坐在圆桌旁把玩银质酒杯，身体没有起身行礼，镜头轻微推近。
光影设计：杯沿反射出他带着轻蔑笑意的下半张脸，烛火的暖光照亮下颌线，眼神深陷在眉骨的阴影中。
动作与情绪：指尖漫不经心摩挲杯壁，嘴角挂着若有若无的冷笑——这不是疏忽，而是刻意的轻慢。全程没有正眼看向大门方向。
声音设计：银杯碰到指节发出清脆的金属碰撞声，在安静的大厅中格外刺耳。
*00:06 - 00:10 | 鬣狗围桌 / Slow Semi-circle Pan*
【慢速半环绕 / Slow Semi-circle Pan】镜头沿圆桌半环绕扫过一群大腹便便、穿暗红皮革贵族服的男权领主，他们靠在椅背上交换眼色。
光影设计：粗短手指上的戒指在烛光中反光刺眼，暗红皮革在暖光下呈现血液凝固般的色泽，阴影在他们之间形成密谋的分割线。
动作与情绪：交换眼色，粗短手指敲击桌面，身体松弛而警觉——群狼在等待猎物露出破绽。
声音设计：低沉弦乐开始从底部压入，形成不安的基调。最后停在圆桌空位与大门方向，给下一段公主入场留出空间。</shot>
<shot id="P02" duration="8" characters="母亲@图1" scenes="庄园主厅@图4">【导演视觉与听觉宣言 / Director's Vision】温暖现实主义家庭剧质感，9:16 竖屏构图，以庄园主厅暖光为视觉基底，傍晚斜阳穿过百叶窗在木地板上投下条纹光影，营造"等待中藏着一丝不安"的家庭氛围。
*00:00 - 00:04 | 窗边身影 / Waiting Figure*
【固定中景 / Fixed Medium Shot】固定镜头，母亲站在窗边，手扶窗框，百叶窗的影子斜落在她侧脸和深色长裙上。
光影设计：傍晚斜阳穿过百叶窗在地板上投下条纹光影，暖光与逐渐暗下的阴影形成渐进式对比，暗示等待的焦虑在蔓延。
动作与情绪：她望着窗外逐渐暗下来的庭院，呼吸带动肩膀轻微起伏——表面平静，但握着窗框的手指微微收紧。
声音设计：环境音是远处座钟滴答声和厨房里煮水声，安静中带着一丝等待的煎熬。
*00:04 - 00:08 | 转身对话 / Reveal Turn*
【揭示摇镜 / Reveal Pan】听到脚步声，母亲缓缓转身，跟拍镜头随她的视线摇向门口，浅景深虚化背景。
光影设计：壁炉火光在她的侧脸轮廓上跳动，勾勒出温柔而克制的表情线条，暖色光在她瞳孔中闪烁。
动作与情绪：她脸上浮现关切而克制的微笑——想表现轻松但眉间藏着担忧，嘴唇微张欲言又止。
声音设计：脚步声由远及近，壁炉木柴轻轻噼啪作响，布料随着转身发出柔和的摩擦声。</shot>
</shots>
```

**注意：这是唯一输出格式，不要输出 Markdown 标题或表格。** 每个 `<shot>` 标签包含一个完整的剧情点，内部由时间码 `*HH:MM - HH:MM | 中文 / English Title*` 分隔为多个子镜头。每个子镜头内，标签信息块按"4 必选 + N 可选"组合：`【镜头类型】`、`光影设计`、`动作与情绪`、`声音设计` 四项必须存在；`【情绪空镜 / Cutaway】`、`视觉捕捉`、`演员调度与台词`、`听觉突变` 等按需添加。duration 属性填充总时长，最长 15 秒。

## 输出规范

- 使用与剧本原文相同的语言，勿擅自翻译
- 提示词采用叙事描述式，不要用关键词堆叠式
- 每条提示词必须完整可用
- 子镜头之间的时间码必须连续、不重叠、不跳秒
- 每个子镜头之间用换行分隔，不加额外空行
