# Seedance 2.0 分镜编写技能

[技能说明]
    将导演的讲戏内容转化为 Seedance 2.0 格式的动态视频提示词。每个剧情点 = 一段完整叙事 = 一条提示词 = 一次 Seedance 2.0 生成任务。段落内可包含多组镜头（如蒙太奇、连续切换）。提示词中使用 @引用语法关联人物和场景素材，输出可直接复制到 Seedance 2.0 平台生成视频。

[文件结构]
    seedance-storyboard-skill/
    ├── SKILL.md                                    # 本文件（技能流程说明）
    ├── seedance-prompt-methodology.md              # Seedance 2.0 提示词方法论
    ├── examples/
    │   └── seedance-prompt-examples.md             # Seedance 2.0 官方提示词参考示例
    └── templates/
        └── seedance-prompts-template.md            # Seedance 提示词产出模板（输出格式定义）

[执行流程]

    第一步：读取上游产物
        - 读取导演讲戏本
        - 参考「已有素材库」中的角色和场景清单，了解可用的素材及 @引用编号
        - 读取 seedance-prompt-methodology.md
        - 读取 examples/seedance-prompt-examples.md，了解官方提示词的风格和结构

    第二步：建立素材对应表
        - 根据「已有素材库」中的角色资产和场景资产，为本集涉及的素材分配 @引用编号
        - 只有「已有素材库」中有对应资产的人物/场景才分配 @引用
        - 不在已有素材库中的人物（群演、一次性配角）不进对应表，在提示词中直接用文字描述
        - 在文档头部建立对应表
        - 具体格式见 templates/seedance-prompts-template.md

        场景素材的编号规则（重要）：
        - scene-prompts.md 中的九宫格是"生成格式"——用于一次性生成场景参考图
        - 生成后，用户会将九宫格中的每个格子单独提取出来，作为独立的场景参考图
        - 因此在素材对应表中，每个场景必须独立编号为一个 @图片，不能将整张九宫格作为一个 @图片
        - 编号顺序：先人物，再场景
        - 平台约束（单条提示词维度）：
        - 以下限制是针对每条提示词（每次 Seedance 生成任务），不是全文档限制
        - 图片 ≤ 9 张 / 条
        - 视频 ≤ 3 个 / 条
        - 音频 ≤ 3 个 / 条
        - 总文件数 ≤ 12 个 / 条
        - 素材对应表是全文档的总映射，可以超过单条限制

    第三步：拆解剧情点为多镜头序列

        根据剧情点的时长和叙事密度，将其拆分为 2-3 个子镜头（Shot），每个子镜头 3-6 秒。
        总时长 = 各子镜头时长之和。

        每个 Shot 需承担以下三种叙事职能之一：

        A. Establish（建立空间）
           - 职能：确立场景空间、感官基调、环境氛围
           - 位置：通常为 P 的第一个 Shot
           - 景别：全景 / 远景 / 大远景
           - 优先突出：空间建立、光影主基调、环境音

        B. Act（展现角色）
           - 职能：展示角色动作、对白互动、情绪反应
           - 位置：P 的核心内容段
           - 景别：中景 / 近景 / 特写
           - 优先突出：角色表演、台词、微表情、动作细节

        C. Bridge（衔接转场）
           - 职能：段内转场、情绪收束、为下一 P 做铺垫
           - 位置：P 的最后一个 Shot
           - 景别：视衔接需求而定
           - 优先突出：运镜运动、声音过渡、情绪转变
           - 最后一个 Bridge 必须为下一 P 的 Establish 做空间或情绪铺垫

        时长分配参考：
        | 总时长 | Shot 数 | 推荐分配 |
        |--------|--------|---------|
        | ≤ 8 秒 | 2 个    | Establish + Act 或 Act + Bridge |
        | 10-15 秒 | 3 个  | Establish + Act + Bridge |

    第四步：构建每个子镜头的内容

        每个 Shot 的内容须包含以下标签结构（4 必选 + N 可选），按 templates/seedance-prompts-template.md 中的示例格式排列：

        4 必选（每个子镜头都必须存在）：
        - 【镜头类型 / English Shot Type】— 景别+运镜的主体描述
        - 光影设计：— 光源方向、色温、明暗对比
        - 动作与情绪：— 角色面部细节、肢体语言、心理状态
        - 声音设计：— 环境音/动作音效/配乐/台词渲染

        N 可选（按段职能按需添加）：
        - 【情绪空镜 / Cutaway】— 0.5 秒极速闪切，强化情绪或预兆
        - 视觉捕捉：— 具体物件特写（道具、伤痕、环境细节）
        - 演员调度与台词：— 走位、对白、音色指定
        - 听觉突变：— 音效骤变/真空抽离/声场转换
        - 构图与运镜：— 当需要独立描述空间布局或特殊机位时

        排列格式（完整示例见 templates/seedance-prompts-template.md）：

        *[时间码] | [中文标题] / [English Title]*
        【镜头类型 / English】[运镜主体描述]
        光影设计：[描述]
        动作与情绪：[描述]
        声音设计：[描述]
        【情绪空镜 / Cutaway】（可选）[描述]

        维度分配策略（决定每个 Shot 写什么、不写什么）：

        | Shot 类型 | 必须突出（至少 1 项） | 可选突出 | 可以不写 |
        |-----------|---------------------|---------|---------|
        | Establish | 空间建立、光影基调 | 运镜运动、环境音 | 角色表情、台词 |
        | Act | 角色动作、台词 | 微表情、动作音效 | 环境音、全局光影 |
        | Bridge | 运镜运动、声音过渡 | 情绪转变 | 新角色引入 |

        时间码规则：
        - 格式 `*00:00 - 00:03 | 中文标题 / English Title*`
        - 分段时间码连续，不重叠不跳秒
        - 英文标题使用专业电影摄影术语（Establishing Shot / Insert Close-up / Slow Pan / Tracking Shot / Over-the-Shoulder 等）

        切换方式（每个 Shot 开头注明）：
        - 硬切 / 叠化 / 淡入淡出 / 快速摇镜 / 匹配剪辑

        示例（一个 P 拆为 3 个 Shot，以下内容放入 `<shot>` 标签内部）：
        ```xml
        【导演视觉与听觉宣言 / Director's Vision】真人写实奇幻短剧质感，16:9 宽银幕构图，以宏伟圆形议事大厅为视觉基底，冷蓝高窗光与桌面烛火形成冷暖分裂，制造"哀悼被权力亵渎"的压迫氛围。
        *00:00 - 00:03 | 穹顶压下 / Descending Establishing Shot*
        镜头从高耸穹顶缓慢俯冲，古老魔法图腾和王室纹样掠过画面，灰蓝天光从左上方斜落，最终压到中央圆桌。环境音是大厅空旷回声、远处烛火轻响和低沉男声私语。
        *00:03 - 00:06 | 银杯与轻蔑 / Insert Close-up*
        硬切到手部特写，他坐在圆桌旁把玩银质酒杯，杯沿反射出他带着轻蔑笑意的下半张脸，身体没有起身行礼。镜头轻微推近，银杯碰到指节发出清脆声。
        *00:06 - 00:10 | 鬣狗围桌 / Slow Semi-circle Pan*
        镜头沿圆桌半环绕扫过一群大腹便便、穿暗红皮革贵族服的男权领主，他们靠在椅背上交换眼色，粗短手指敲击桌面，戒指反光刺眼。低沉弦乐开始压入，最后停在圆桌空位与大门方向，给下一段公主入场留出空间。
        ```

    第五步：撰写导演视觉与听觉宣言

        每个 P 的第一个 Shot 之前，输出一段「导演宣言」，自然融合以下 4 个要素（非列表堆砌）：

        1. 视觉风格声明：项目的视觉风格 + 画幅
        2. 场景基底：描述本段的核心场景
        3. 光影主基调：一句话概括本段的主要光影设计
        4. 情绪目标句：制造"[情绪]"的氛围

        格式：
        【导演视觉与听觉宣言 / Director's Vision】[风格]，[画幅]构图，以[场景]为视觉基底，[光影描写]，[情绪目标句]。

        示例：
        【导演视觉与听觉宣言 / Director's Vision】真人写实奇幻短剧质感，16:9 宽银幕构图，以宏伟圆形议事大厅为视觉基底，冷蓝高窗光与桌面烛火形成冷暖分裂，制造"哀悼被权力亵渎"的压迫氛围。

    第六步：输出
        只输出 XML 格式，不输出 Markdown。严格按照 templates/seedance-prompts-template.md 定义的 XML 格式输出。
        一个 `<shot>` 标签 = 一个剧情点（P），内含完整的多段子镜头内容。

[Seedance 2.0 提示词写法核心规则]

    叙事描述式
        - 用完整的导演式段落描述，不要关键词堆叠
        - Seedance 2.0 擅长理解长段叙事性提示词
        - 参考官方模板风格：连续段落，包含运镜、动作、光影、声音的融合描述

    运镜描述
        - 用具体方向和动作描述镜头运动
        - "镜头从侧脸缓缓推向窗外夜色" ✓
        - "推镜头" ✗（太简略）
        - 常用运镜：推镜/拉镜、横摇/纵摇、环绕、跟拍、升降、手持

    动作描述
        - 用具体的物理动作，避免抽象概念
        - "她揉了揉太阳穴，目光从屏幕移开，靠向椅背" ✓
        - "她感到疲惫" ✗

    时长控制
        - 遵循导演建议的时长
        - 底层规律：每个连续镜头内 1 拍 ≈ 2.5 秒屏幕时间，节拍太密动作会糊、跳、不自然
        - 多镜头段落：节拍分布在多个镜头切换中，每个镜头各自遵守密度约束，总节拍可超单镜头上限
        - 头尾安全区：每次 Seedance 生成的前 0.5s 和后 0.5s 为安全区，不放关键内容

    声音/台词
        - 台词用引号标注
        - 可指定语气/声音特征
        - 可指定背景音乐风格
        - 可指定环境音

    视觉风格一致性
        - 提示词中的场景描述、光影氛围、镜头审美必须与 ## 项目配置 中的「视觉风格」保持一致
        - 如视觉风格为"3D CG"，则运镜描述应模拟虚拟摄像机运动而非手持摄影
        - 如视觉风格为"真人写实"，则光影描述应基于物理光源逻辑
        - 如视觉风格为"国漫/日漫"，则镜头语言应偏向动画感的构图和运动

    画面比例适配
        - 构图需适配 ## 项目配置 中的「画面比例」
        - 16:9（宽屏）：适合横构图、双人对话、全景展示、左右空间丰富
        - 9:16（竖屏）：适合单人近景、纵向走位、上下分层构图、短视频感

    目标媒介适配
        - 提示词的节奏、时长、镜头选择需适配 ## 项目配置 中的「目标媒介」
        - 电影：偏长镜头（10-15s），电影感运镜（推拉摇移升降），宽幅构图
        - 短剧：偏短镜头（5-8s），快节奏，近景/特写为主，信息密度高
        - 漫剧：静态感强，画面如漫画格，配合旁白/字幕打断，镜头运动少
        - MV：节奏与音乐同步，可抽象化，画面随节拍切换
        - 广告：短促有力（4-8s），产品/品牌视觉突出，开头即抓注意力

[群演/一次性配角处理]
    导演讲戏本中可能提到不在已有素材库中的人物（群演、一次性配角）。处理方式：
    - 不为这些人物分配 @引用编号
    - 在提示词中直接用文字描述其外观和动作
    - 外观描述从导演讲戏本的导演阐述中提取（导演已在阐述中具体描述了这些角色的外观）
    - 示例：导演阐述中提到"路人甲侧头对同伴低声说"，讲戏本中描述其为"尖脸眯缝眼的白袍学员"
      → 提示词中写"一个尖脸眯缝眼的白袍学员侧头低声说..."，不使用 @引用

[禁忌规则]
    - 不要使用否定句（AI 不理解否定，可能产生相反效果）
        "不要移动镜头" ✗ → "镜头保持固定" ✓
    - 不要重复导演讲戏本和人物/场景提示词中已有的静态内容描述
        重点描述"变化"：动作、运动、情绪转变
    - 不要在一条提示词中塞入叙事上不相关的场景
        一条提示词 = 一个完整的叙事段落（可含多组镜头，但叙事连续）
    - 不要使用与导演讲戏本和人物/场景提示词矛盾的描述
    - 不要为不在已有素材库中的人物使用 @引用

[注意事项]
    - seedance-prompt-methodology.md 是核心方法论，必须遵守
    - 参考 examples/seedance-prompt-examples.md 了解官方推荐的提示词风格和结构

【硬性约束】每个剧情点的提示词必须满足以下条件：

1. **导演视觉与听觉宣言**
   每个 P 的提示词必须以「导演宣言」开头，包含视觉风格、场景基底、光影主基调、情绪目标句 4 个要素。

2. **多镜头结构**
   ≤ 8 秒 → 至少 2 个子镜头；10-15 秒 → 至少 3 个子镜头。子镜头之间用时间码分隔，时间码连续无断裂。

3. **每段独立音频设计**
   每个子镜头必须包含音频指导（环境音 / 动作音效 / 配乐 / 台词音色），根据子镜头类型分配不同的音频重心。

4. **禁止 @引用——纯文字叙事**
   提示词正文禁止使用 @图N / @图片N / @A{id} 等引用格式。角色和场景只使用文字名称引用。

5. **角色和场景名称与资产表一致**
   提示词中使用的角色名和场景名必须与已有素材库中的名称完全一致（含括号内后缀），不得自行改写、缩写或翻译。

6. **完整覆盖与衔接**
   每个 P 必须覆盖本段所有出场人物和场景，最后一个子镜头必须为下一个 P 做铺垫（最后一个 P 除外）。

【旧数据兼容】
   以上硬性约束中的 2、3、5 条仅在总时长 ≥ 8 秒时必须执行。总时长 < 8 秒时可使用单镜头格式。
