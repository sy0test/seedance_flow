# 内容合规审核技能

[技能说明]
    内容合规审核技能，检查各阶段产出是否触碰 gpt-image (OpenAI) 的平台内容限制。此 skill 在每次审核的第二步使用，与阶段专属的业务审核 skill 配合。

[审核对象]
    根据当前阶段不同：
    - 阶段一：导演分析产出（导演讲戏本、人物清单、场景清单）
    - 阶段二：服化道设计产出（角色提示词、场景提示词）
    - 阶段三：分镜师的 Seedance 2.0 提示词

[审核流程]

    第一步：读取待审核内容
        - 读取当前阶段的产出内容

    第二步：逐项检查
        按照下方验收清单逐项检查

    第三步：输出结果
        - 全部通过 → PASS
        - 任一未通过 → FAIL + 问题清单

[验收清单]

    版权 IP 限制（OpenAI 严格拦截）
        □ 是否不包含已知版权 IP 角色名称（迪士尼、漫威、DC、哈利波特、宝可梦等）？
        □ 是否不包含已知版权 IP 的形象/设定描述？
        □ 是否不试图复刻经典影视片段或知名艺术作品？

    政治敏感（OpenAI 严格拦截）
        □ 是否不涉及反对宪法基本原则？
        □ 是否不涉及危害国家安全/煽动民族仇恨？
        □ 是否不涉及歪曲英雄烈士/宣扬恐怖主义？
        □ 是否不包含选举/竞选相关政治内容？

    色情/裸露（OpenAI 拦截最严格）
        □ 是否不包含淫秽色情内容或性行为描写？
        □ 是否不包含性暗示/软色情？
        □ 服装设计是否避免过度暴露？
        □ 是否不包含裸体或半裸描写？

    暴力/血腥（OpenAI 中度拦截，虚构打斗可接受）
        □ 武打/格斗场景是否使用虚构角色？
        □ 是否不过度写实血腥（伤口、断肢、大量血液）？
        □ 是否不包含虐待、酷刑、自残描写？
        □ 是否不包含赌博/诈骗/犯罪指导？

    未成年人保护（OpenAI 严格拦截）
        □ 是否不涉及任何形式对未成年人的侵害内容？
        □ 是否不涉及危害未成年人身心健康的内容？
        □ 未成年人角色是否不涉及成人类场景？

    仇恨/歧视（OpenAI 严格拦截）
        □ 是否不包含基于性别/年龄/地域/民族/种族/宗教/性取向的歧视？

    虚假信息
        □ 是否不涉及散布谣言/歪曲事实？

    宗教（OpenAI 相对宽松，宗教场景可描绘）
        □ 是否不涉及宣扬邪教？
        □ 宗教场景是否尊重文化传统、不产生冒犯？

    名人面容（OpenAI 相对宽松，但仍建议避免）
        □ 角色外观是否与真实公众人物不相似？
        □ 提示词中是否不包含真实公众人物姓名？

[常见被拒原因（gpt-image 高频拦截）]

    以下内容在 gpt-image 中容易被拦截，即使意图合法也建议避免：
    1. 裸体/半裸/内衣/泳装类描述
    2. 性暗示姿势或场景
    3. 过度写实的伤口/血迹描写
    4. 真实公众人物姓名或相似描述
    5. 知名商标/品牌/角色名称
    6. 选举/政治人物相关
    7. 未成年人涉成人场景
    8. 极端暴力/恐怖画面

[输出规范]
    PASS 格式：
        ✅ **合规审核：PASS**
        内容未触碰平台红线。

    FAIL 格式：
        ❌ **合规审核：FAIL**

        **问题1**：[具体违规描述]
        - 位置：[如 人物设计 > 角色名 / P03 提示词]
        - 触碰红线：[哪条规则]
        - 修改方向：[如何修改以规避]

        **问题2**：...

        ---
        **风险等级**：
        1. 🔴 必须修改（触碰绝对禁止红线）：[列出]
        2. 🟡 建议修改（可能触发误杀）：[列出]
