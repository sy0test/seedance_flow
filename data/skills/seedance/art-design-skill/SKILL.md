# 服化道设计技能

[技能说明]
    美术设计技能，将导演提供的人物清单和场景清单转化为可直接用于文生图工具生成参考图的详细提示词。

    人物提示词出图格式：一张图，左侧面部特写，中间竖椭圆形人相框一张特写，右侧全身正面/侧面/背面设定图，白色背景。
    场景提示词出图格式：每个场景一张图，独立条目。

[执行流程]

    第一步：读取上游产物
        - 读取导演分析产出中的人物清单和场景清单
        - 读取 gemini-image-prompt-guide.md 了解提示词写法规范
        - 读取 examples/ 下的示例文件，了解高质量提示词的写法标准
        - 读取已有的 assets/character-prompts.md 和 assets/scene-prompts.md（如存在），了解已设计的人物和场景
        - 根据人物清单和场景清单中的"素材状态"列，只为标注为"新增"或"变体"的项设计提示词
        - "复用"项跳过，不需要设计

    第二步：设计人物造型提示词
        为每个人物编写设定提示词：

        出图布局：
        - 一张图，左侧面部特写，中间竖椭圆形人相框一张特写，右侧全身正面/侧面/背面三视图设定图
        - 白色干净背景
        - 角色设定图风格

        提示词必须包含：
        - 角色整体定位（年龄、性别、国籍/民族特征）
        - 面部细节：脸型、五官、肤色、发型/发色、表情
        - 体型：身高、体态
        - 服装：款式、颜色、材质、细节
        - 配饰：手表、耳环、眼镜、包等
        - 鞋子
        - 整体气质

    第三步：设计场景环境提示词
        为导演分析出的每个场景独立编写提示词，格式与人物提示词一致：

        每个场景一个独立条目，格式：
        ## 场景名（epXX）

        **提示词**：
        [完整场景描述提示词]

        提示词必须包含：
        - 地点类型与空间布局
        - 时间（影响光照）
        - 光源类型与光线方向
        - 整体色调/色彩倾向
        - 关键道具/家具/物件
        - 空间纵深与层次
        - 氛围/情绪
        - 风格：必须与 ## 项目配置 中的「视觉风格」（如真人写实/3D CG/国漫/日漫等）保持一致，在提示词中明确体现该风格的特征


    第四步：输出
        按照 templates/art-design-template.md 定义的格式，分别写入两个文件：
        - 人物提示词 → 追加到 assets/character-prompts.md
        - 场景道具提示词 → 追加到 assets/scene-prompts.md
        首集时创建文件，后续集数追加新增/变体条目到文件末尾。

[提示词写法原则]
    参考 gemini-image-prompt-guide.md，核心要点：

    - 叙事描述式：用完整段落描述，不要关键词堆叠
    - 具体化：所有描述必须具体到可视化的程度
        - "穿红色衣服" ✗ → "穿深红色修身棉袄外套，内搭碎花棉布衫" ✓
        - "室内场景" ✗ → "现代都市写字楼的开放式办公区，大部分工位已空" ✓
    - 摄影术语融入自然语言
    - 情绪通过视觉细节传达，不要抽象描述

[注意事项]
    - gemini-image-prompt-guide.md 是提示词写法的核心参考
    - 人物提示词必须明确"左侧面部特写 + 中间椭圆形人相框特写 + 右侧三视图"的布局要求
    - 场景提示词要包含足够的环境细节以确保场景可信度和一致性
    - 所有提示词必须体现 ## 项目配置 中的「视觉风格」——如为"3D CG"则提示词应包含3D渲染术语和光影特征，如为"国漫"则应有国漫线条和色彩特征
    - 提示词的构图和氛围需适配「目标媒介」：电影→电影感宽银幕构图，短剧→竖屏/近景为主，漫剧→漫画格般的平面感，MV→强风格化视觉，广告→产品聚焦
    - 场景图和角色设定图的生成需注意「画面比例」：16:9 → 宽银幕构图、横向上有空间；9:16 → 竖屏构图、纵向视觉为主
    - 如果是为变体设计（如同一人物的冬装版），需在提示词中注明与原版的关联和差异

    【硬性要求】人物提示词必须以「{visualStyle}风格，画面比例{aspectRatio}」开头。
    例如 visualStyle 为"3D中国古风"、aspectRatio 为"16:9"时：
        正确："3D中国古风风格，画面比例16:9，年轻男性，长发束发，白色古装长衫..."
        错误（缺少风格开头）："年轻男性，长发束发，白色古装长衫..."
    这条规则优先级高于所有其他规则，不得违反。
