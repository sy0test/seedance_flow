# 服化道设计产出模板

---

## 【必备】XMl 结构化输出（必须先满足此要求）

在输出服化道设计内容时，**无论 markdown 格式如何排列，输出末尾必须包含**以下 XML 容器标签：

```xml
<characterPrompts>
<character name="[角色名]" type="新增/变体/复用">[该角色对应的完整提示词内容]</character>
<character name="[角色名2]" type="新增/变体/复用">[完整提示词内容]</character>
</characterPrompts>
```

场景提示词同理：

```xml
<scenePrompts>
<scene name="[场景名]" type="新增">[完整场景描述提示词]</scene>
</scenePrompts>
```

**提示词内容必须与前面 markdown 正文中的一致**，不得省略、截断或简化。
此 XML 是前端解析结构化数据的唯一来源，缺少它将导致页面无法正常展示。

## 场景提示词格式

每个场景独立一个条目，格式与人物提示词相同：

```markdown
# 场景提示词

## 庄园主厅（ep01）

**提示词**：
[完整场景描述提示词，包含视角、光线、色调、关键道具、氛围]

---

## 庄园地牢（ep01）

**提示词**：
[完整场景描述提示词]

---

## ep02 场景（ep02 新增）

（后续集数的新增场景追加在文件末尾）
```

## 输出规范

- 使用与剧本原文相同的语言，勿擅自翻译
- 提示词采用叙事描述式，不要用关键词堆叠式
- 直接输出完整提示词，不要逐条解释设计理由
- 每个提示词必须完整可用，用户可以直接复制到文生图工具生成图片
- 每个条目标注创建集数（如 ep01 新增），便于追溯
- 如果是变体设计（如同一人物的冬装版），需在提示词中注明与原版的关联和差异
- 复用项不重复写入，只为"新增"和"变体"项编写提示词
- 场景顺序按照导演分析中的场景清单排列
